## Instalación proyecto con GULP:

### 1. Instalación Node.js v22.18.0
	-> https://nodejs.org/en/blog/release/v22.18.0

### 2. Inicialización GULP
Dentro de la carpeta GULP encontrarás un README con las instrucciones para la instalación

## 3. Crear un repositorio en GIT:
Todos los proyectos utilizan control de versiones, y lo más común es utilizar GIT. Por eso es importante que aprendas a utilizarlo y vayas subiendo el progreso de tu desarrollo.
- Si no tienes cuenta puedes crearla en: https://github.com/
- Si prefieres usar la terminal para manejarte por GIT eres un Crack. Si prefieres una interfaz bonita te comparto esta herramienta: https://github.com/apps/desktop
- si todo esto te suena desconocido, te comparto un tutorial: https://www.youtube.com/watch?v=TuOQBfhp-r0

P.D.: te dejo el gitignore en la carpeta recursos, para que no subas archivos innecesarios

## 4. Primeros pasos una vez hecha la instalación:

1. Modificar el archivo variables.scss con las variables del proyecto, para el desarrollo del Tema siguiendo el UI Kit del diseño (variables, mixins, componentes globales)
2. Exportar los iconos de Figma en formato SVG y construir una fuente iconográfica
3. Desarrollo de componentes comunes (Header y footer). Todo debe desarrollarse teniendo en cuenta mobile first.

    **¡Atentos a no duplicar componentes! Siempre hay una solución ;)**

4. Desarrollo de la primera página y componentes teniendo en cuenta el Atomic Design y la metodología BEM
